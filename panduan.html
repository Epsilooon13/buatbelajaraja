PANDUAN PENGGUNAAN

Soalmu. Web kuismu.

Web ini berisi 12 soal contoh BGP. Kamu dapat menggunakan soal sendiri dengan empat pilihan dan satu jawaban benar per soal.

1. Mulai latihan

  1. Pilih topik dan jumlah soal. Pilih Semua soal untuk memakai seluruh bank atau seluruh topik terpilih.
  2. Tentukan apakah urutan soal dan pilihan jawabannya diacak, lalu klik Mulai latihan.
  3. Klik A/B/C/D. Jawaban dikunci dan pembahasan langsung muncul. Lanjutkan dengan Soal berikutnya.
  4. Lihat skor akhir dan buka setiap soal pada Ulasan jawaban. Gunakan Ulangi yang belum benar untuk berlatih ulang.

Skor = jumlah benar ÷ seluruh soal dalam sesi × 100, dibulatkan ke bilangan bulat. Mengakhiri sesi lebih awal membuat soal yang belum dijawab bernilai 0. Jika jumlah soal yang tersedia kurang dari permintaan, aplikasi menggunakan semua yang tersedia. Ketika opsi diacak, posisi kunci dibagi merata A/B/C/D dengan selisih paling banyak satu soal; kunci tetap terikat pada isi jawaban.

2. Isi bank soal dari Excel

  1. Unduh contoh CSV. Buka di Excel melalui Data → From Text/CSV bila seluruh teks masuk ke satu kolom. Pilih encoding UTF-8 dan delimiter koma.
  2. Ganti atau tambahkan soal. Satu baris untuk satu soal. Jangan gabungkan sel.
  3. Simpan file kerja Excel secara terpisah jika diperlukan. Ekspor sheet soal melalui Save As → CSV UTF-8 (Comma delimited).
  4. Di web kuis, klik Bank soal → Pilih file CSV. Setelah pemeriksaan berhasil, klik Gunakan bank soal ini.
Kolom wajibIsi
idID unik, misalnya 1, 2, atau BGP-001.
kategoriNama topik bebas: BGP, OSPF, EIGRP, dan lainnya.
pertanyaanTeks soal. Baris baru di dalam satu sel didukung.
opsi_a sampai opsi_dIsi empat pilihan jawaban.
jawabanSatu huruf A, B, C, atau D sesuai posisi opsi dalam CSV.
pembahasanPenjelasan jawaban. Isi seluruh kolom wajib.

Kolom tambahan seperti sumber boleh disertakan dan diabaikan oleh aplikasi. Maksimal 5 MB dan 5.000 soal. Pemisah koma, titik koma, dan tab didukung. Koma atau tanda kutip dalam kalimat akan ditangani saat ekspor CSV dari Excel. Aplikasi menolak seluruh impor jika ada baris rusak agar soal tidak hilang tanpa diketahui.

Impor di halaman ini hanya berlaku selama halaman tetap terbuka.

Memuat ulang halaman akan kembali ke CSV yang dipasang di hosting. Riwayat nilai dan file yang diimpor tidak disimpan ke server. Jangan menutup halaman jika masih mengerjakan sesi.

Mengedit source code dan alamat web

Ekstrak paket ZIP lalu buka foldernya melalui VS Code → File → Open Folder. Edit index.html untuk nama dan teks; style.css untuk tampilan; script.js dan quiz-core.js untuk fungsi kuis; serta soal.csv untuk isi soal. Simpan perubahan dan uji.

Edit di komputer tidak otomatis mengubah situs yang sudah terbit. Unggah perubahan ke hosting atau GitHub yang dipakai. Untuk versi Sites, kamu dapat melampirkan hasil edit di percakapan pemiliknya dan meminta pembaruan.

Alamat Sites diubah melalui Sites → pilih situs → Settings → Change URL. Domain sendiri seperti buatbelajaraja.my.id didaftarkan secara terpisah, lalu dihubungkan melalui pengaturan domain dan DNS. Dokumentasi resmi OpenAI tentang alamat Sites.

3. Publikasikan di GitHub Pages

Paket ZIP berisi website statis siap unggah. Hosting GitHub Pages tersedia untuk repository publik dengan akun GitHub Free. Dokumentasi GitHub Pages.

  1. Ekstrak kuis-jaringan-github-pages.zip di komputer.
  2. Di GitHub, buat repository baru bernama buatbelajaraja dengan visibilitas Public. Jika memakai proyek lama, cadangkan file lama terlebih dahulu.
  3. Buka repository, pilih Add file → Upload files. Unggah semua file hasil ekstrak, termasuk index.html, style.css, quiz-core.js, script.js, soal.csv, dan panduan.html. Unggah isinya, bukan ZIP atau folder pembungkus. Klik Commit changes.
  4. Buka Settings → Pages. Pada Build and deployment, pilih Deploy from a branch.
  5. Pilih branch main, folder /(root), lalu Save.
  6. Tunggu penerbitan selesai. Buka link yang muncul di menu Pages. Untuk nama repository di atas, pola alamatnya adalah https://USERNAME.github.io/buatbelajaraja/; ganti USERNAME dengan username GitHub.

Alur pengaturan branch mengacu pada panduan resmi GitHub. Domain pribadi opsional dan dapat dipasang kemudian melalui pengaturan custom domain.

4. Ganti bank soal untuk semua pengunjung

  1. Ekspor soal terbaru dari Excel dengan nama tepat soal.csv.
  2. Uji dahulu melalui tombol Bank soal agar formatnya valid.
  3. Di repository GitHub, buka Add file → Upload files dan unggah pengganti soal.csv ke folder yang sama dengan index.html. Perhatikan huruf kecil pada nama file.
  4. Klik Commit changes, tunggu penerbitan Pages selesai, kemudian muat ulang web kuis.

Di versi pribadi yang dibuat melalui ChatGPT, kamu juga dapat melampirkan CSV dan meminta penggantian bank soal bawaan. Tombol impor di browser tidak mengubah website untuk pengunjung lain.

5. Alternatif hosting cPanel

Ekstrak ZIP dan unggah isinya melalui File Manager ke document root website. Untuk domain utama biasanya public_html; untuk domain tambahan atau subdomain, lihat document root di menu Domains. Pastikan index.html langsung berada di folder tersebut. Cadangkan website yang sudah ada sebelum mengganti file. Aktifkan SSL setelah DNS domain mengarah ke hosting. Panduan upload IDCloudHost.

Catatan materi

Soal contoh disusun untuk latihan mandiri dan bukan soal ujian resmi Cisco. Tiap baris contoh mencantumkan sumber teknis. CSV beserta kunci dapat diakses pengunjung; aplikasi ini belum menggunakan login, leaderboard, atau penilaian di server.
