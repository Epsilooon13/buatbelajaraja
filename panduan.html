Panduan latihan

Pilih sesi

Klik Materi, pilih modul dan submodul, lalu Tambahkan materi. Ulangi untuk beberapa materi sekaligus. Tekan × untuk menghapus satu pilihan; tanpa pilihan khusus berarti semua materi. Isi jumlah soal sendiri, atau tekan Semua. Jika soal tersedia lebih sedikit, sesi menggunakan seluruh soal yang tersedia.

Pilih Tanpa timer atau waktu 10, 20, 30, atau 45 detik per soal. Saat jawaban dipilih atau waktu habis, jawaban dikunci dan timer berhenti. Mode Belajar menampilkan pembahasan langsung; Mode Ujian menampilkan pembahasan dan skor setelah selesai. Tekan Soal berikutnya setelah selesai membaca. Timer tetap berjalan saat tab ditinggalkan atau dialog mengakhiri sesi terbuka.

Cari materi

Buka Materi, lalu ketik nama atau kode seperti HSRP atau 8.6. Pilih hasil untuk menambahkan modul atau submodul ke daftar materi latihan. Dropdown tetap tersedia. Tekan Escape untuk menghapus pencarian; tombol panah membantu berpindah hasil.

Prioritaskan soal yang sering salah

Aktifkan pilihan ini untuk mencampurkan sekitar 70% soal yang perlu diulang dengan soal lain, jika tersedia. Soal baru diutamakan untuk melengkapi campuran. Setelah dijawab benar dua kali berturut-turut, suatu soal keluar dari prioritas sampai kamu salah lagi.

Jawaban salah dan waktu habis tercatat setelah jawaban dikunci. Soal yang belum dikerjakan saat sesi diakhiri tidak menambah catatan kesalahan. Jika belum ada catatan, latihan berjalan seperti biasa.

Catatan tersimpan di browser/perangkat ini, mulai dari penggunaan versi ini. Menghapus data situs dapat menghapus catatan; catatan tidak tersinkron antarperangkat. Jika penyimpanan tidak tersedia, catatan hanya bertahan selama halaman terbuka. Gunakan satu tab latihan untuk pencatatan yang konsisten.

ID soal harus tetap unik dan stabil. Perubahan pertanyaan, opsi, atau kunci memulai catatan baru untuk soal tersebut.

Lanjutkan sesi

Sesi disimpan otomatis di browser ini setelah mulai, menjawab, waktu habis, dan pindah soal. Setelah memuat ulang atau membuka kembali halaman, tekan Lanjutkan sesi untuk meneruskan urutan soal dan jawaban yang sama. Buang sesi memerlukan konfirmasi; catatan latihan yang sudah tercatat tetap ada.

Timer soal aktif tetap berjalan saat halaman ditutup. Jika tenggatnya lewat, soal tersebut ditandai Waktu habis ketika dilanjutkan. Soal berikutnya belum berjalan sampai kamu menekan tombol berikutnya. Tanpa timer tidak memiliki tenggat.

Jika soal dalam sesi diubah atau dihapus dari bank soal, sesi lama tidak dapat dilanjutkan. Penambahan soal lain tidak membatalkannya. Penyimpanan hanya berlaku di browser/perangkat ini; gunakan satu tab latihan agar sesi tidak tertimpa.

Mode Belajar dan Mode Ujian

Pilih mode sebelum mulai. Jawaban langsung dikunci saat dipilih dan tidak dapat diubah. Dalam Mode Belajar, hasil dan pembahasan muncul per soal. Dalam Mode Ujian, jawaban ditandai netral dan pembahasan serta skor baru ditampilkan setelah sesi selesai. Kedua mode mendukung pilihan tanpa timer.

Kelola soal di GitHub

Edit soal.csv di repository, lalu simpan melalui Commit changes. Tunggu penerbitan GitHub Pages selesai dan muat ulang halaman. Pengunjung akan menggunakan versi bank soal tersebut.

Header CSV tetap:

id,kategori,pertanyaan,opsi_a,opsi_b,opsi_c,opsi_d,jawaban,pembahasan

Simpan sebagai CSV UTF-8. Setiap ID harus unik, opsi A/B/C/D wajib lengkap, dan jawaban berisi satu huruf A/B/C/D. Teks yang berisi koma perlu dibungkus tanda kutip ganda; gandakan tanda kutip di dalam teks.

Konfigurasi dan output

Untuk menampilkan konfigurasi seperti terminal, bungkus bagian tersebut dengan [cli] dan [/cli] di dalam sel CSV. Output memakai [output] dan [/output]. Format XML, JSON, dan kode lainnya memakai pasangan [xml], [json], atau [code].

Letakkan tag dan isinya pada baris terpisah. Gunakan baris baru sungguhan, pertahankan spasi/indentasi, dan bungkus seluruh nilai CSV dengan tanda kutip ganda. Tanda kutip di dalam nilai harus digandakan. Header CSV tetap sama. Beberapa blok dalam satu sel diperbolehkan; jangan membuat tag bersarang.

Penanda berlaku di pertanyaan, pilihan jawaban, dan pembahasan. Teks biasa tidak membutuhkan penanda. Baris kode panjang dapat digulir ke samping. Dengan keyboard, fokuskan blok atau tombol opsi lalu gunakan panah kiri/kanan; Enter/Spasi pada opsi memilih jawaban. Saat membuka ulasan, pertanyaan lengkap dan blok kode tampil kembali. Pembahasan Mode Ujian tetap menunggu sesi selesai.

Contoh dua bahasa dan tambahan prompt tersedia di README.md dalam paket update. Contoh tidak otomatis ditambahkan ke bank soal. Pastikan file baru content-format.js ikut diunggah.

Kategori modul dan submodul

Gunakan kode dan judul submodul dalam kolom kategori, misalnya 11.5 BGP Path Selection atau 8.6 EIGRP Path Selection. Kode x.y menentukan kelompok soal. Kategori x.y.z digabungkan ke induk x.y.

Nama submodul persis juga dikenali jika tidak ambigu. Beberapa judul lama telah dipetakan dalam curriculum.js. Kategori lainnya tetap dapat dipilih melalui Materi lainnya. Modul dengan 0 soal belum memiliki soal yang cocok.

Upload paket pembaruan

Ekstrak ZIP, lalu unggah semua file hasil ekstrak ke root repository. Jangan unggah file ZIP saja. Paket pembaruan tidak menyertakan soal.csv; tetap gunakan bank soalmu yang sudah ada.

Jika tampilan masih lama, gunakan Ctrl+F5 setelah penerbitan selesai. Bank soal gagal dimuat? Periksa format CSV dan pastikan soal.csv ada di folder yang sama dengan index.html.
