Panduan latihan

Pilih sesi

Klik Materi untuk memilih modul dan submodul. Isi jumlah soal sendiri, atau tekan Semua. Jika soal tersedia lebih sedikit, sesi menggunakan seluruh soal yang tersedia.

Pilih waktu 10, 20, 30, atau 45 detik per soal. Saat jawaban dipilih atau waktu habis, timer berhenti dan pembahasan muncul. Tekan Soal berikutnya setelah selesai membaca. Timer tetap berjalan saat tab ditinggalkan atau dialog mengakhiri sesi terbuka.

Cari materi

Buka Materi, lalu ketik nama atau kode seperti HSRP atau 8.6. Pilih salah satu hasil untuk mengatur modul dan submodul latihan. Dropdown tetap tersedia. Tekan Escape untuk menghapus pencarian; tombol panah membantu berpindah hasil.

Prioritaskan soal yang sering salah

Aktifkan pilihan ini untuk mencampurkan sekitar 70% soal yang perlu diulang dengan soal lain, jika tersedia. Soal baru diutamakan untuk melengkapi campuran. Setelah dijawab benar dua kali berturut-turut, suatu soal keluar dari prioritas sampai kamu salah lagi.

Jawaban salah dan waktu habis tercatat setelah jawaban dikunci. Soal yang belum dikerjakan saat sesi diakhiri tidak menambah catatan kesalahan. Jika belum ada catatan, latihan berjalan seperti biasa.

Catatan tersimpan di browser/perangkat ini, mulai dari penggunaan versi ini. Menghapus data situs dapat menghapus catatan; catatan tidak tersinkron antarperangkat. Jika penyimpanan tidak tersedia, catatan hanya bertahan selama halaman terbuka. Gunakan satu tab latihan untuk pencatatan yang konsisten.

ID soal harus tetap unik dan stabil. Perubahan pertanyaan, opsi, atau kunci memulai catatan baru untuk soal tersebut.

Kelola soal di GitHub

Edit soal.csv di repository, lalu simpan melalui Commit changes. Tunggu penerbitan GitHub Pages selesai dan muat ulang halaman. Pengunjung akan menggunakan versi bank soal tersebut.

Header CSV tetap:

id,kategori,pertanyaan,opsi_a,opsi_b,opsi_c,opsi_d,jawaban,pembahasan

Simpan sebagai CSV UTF-8. Setiap ID harus unik, opsi A/B/C/D wajib lengkap, dan jawaban berisi satu huruf A/B/C/D. Teks yang berisi koma perlu dibungkus tanda kutip ganda; gandakan tanda kutip di dalam teks.

Kategori modul dan submodul

Gunakan kode dan judul submodul dalam kolom kategori, misalnya 11.5 BGP Path Selection atau 8.6 EIGRP Path Selection. Kode x.y menentukan kelompok soal. Kategori x.y.z digabungkan ke induk x.y.

Nama submodul persis juga dikenali jika tidak ambigu. Beberapa judul lama telah dipetakan dalam curriculum.js. Kategori lainnya tetap dapat dipilih melalui Materi lainnya. Modul dengan 0 soal belum memiliki soal yang cocok.

Upload paket pembaruan

Ekstrak ZIP, lalu unggah semua file hasil ekstrak ke root repository. Jangan unggah file ZIP saja. Paket pembaruan tidak menyertakan soal.csv; tetap gunakan bank soalmu yang sudah ada.

Jika tampilan masih lama, gunakan Ctrl+F5 setelah penerbitan selesai. Bank soal gagal dimuat? Periksa format CSV dan pastikan soal.csv ada di folder yang sama dengan index.html.
